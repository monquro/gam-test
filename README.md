# 📸 PHOTO DAY — 내 사진 찍는 날 찾기

포토부스 매장이 있는 **미국 7개 지역과 한국 8개 도시**의 날씨와 공휴일로,
**"사진 찍으러 가기 좋은 날"**을 맞히는 고객 참여형 퀴즈입니다.
다 풀면 사진 찍으러 올 달을 고르고, 그 달에만 쓰는 쿠폰을 받습니다.

- **사이트:** https://gam-test-eight.vercel.app/
- **포트폴리오:** https://jyeomi-portfolio.vercel.app/
- **모든 숫자는 공개 데이터에서 직접 계산했습니다.** 손으로 적은 정답은 없습니다.
- 회사 공식 행사가 아닌 개인 포트폴리오 시제품입니다. 회사 로고 · 내부 데이터는 쓰지 않았고, 쿠폰은 **샘플**입니다.

## 손님이 거치는 화면

```
언어 고르기 (한국어 · English · Español)
  → 나라 고르기 (미국 / 한국) → 매장 지역 고르기 (기타 지역도 있음)
  → 테마 6개 중 하나 고르기 → "○○ 로 찰칵!" → 3 · 2 · 1
  → 3문항 (VS 대결 · O/X · 상황극 · 랭킹 · 숫자 섞어서)
  → 결과 (나의 포토 타입) → 사진 찍으러 올 달 고르기 (날짜는 선택)
  → 그 달 쿠폰 → Google 캘린더 / 휴대폰 캘린더에 약속 추가
```

## 지역마다 다른 퀴즈 — 📍 LOCAL

매장마다 날씨가 다르니 **정답은 지역별로 따로 계산**하고, **지역마다 그 동네에서만 나오는 문제를 하나씩** 넣었습니다.
테마 카드에 📍 LOCAL 스티커가, 문항 위에 "📍 ○○ 한정 문제" 배지가 붙습니다.

## 데이터는 어디서 가져왔나

| 무엇 | 출처 | 범위 |
|---|---|---|
| 날씨 — 강수량 · 최고/최저기온 · 구름양 · 일몰 시각 · 낮 길이 | [Open-Meteo 과거 날씨](https://open-meteo.com/en/docs/historical-weather-api) (ERA5 모델 고정) | 15개 지역, 2016-01-01 ~ 2025-12-31, 하루 단위 |
| 공휴일 | [Nager.Date](https://date.nager.at/) | 미국 · 한국, 2016 ~ 2028년 |
| 검증용 관측 기록 (정답에는 안 씀) | [NOAA GHCNd](https://www.ncei.noaa.gov/products/land-based-station/global-historical-climatology-network-daily) — 미국 관측소 | 호놀룰루 · LA · 댈러스 · 앤아버 |

- 모두 **키나 로그인 없이** 받을 수 있는 공개 데이터입니다.
- 출처 후보는 **Perplexity로 찾고**, 링크를 직접 열어 받을 수 있는지 확인한 뒤 골랐습니다.
- 매장 좌표는 공개된 매장 주소(공식 사이트 · 쇼핑몰 · 지도 서비스)로 정했습니다.

## 세는 기준 — 문항 문장에도 적었습니다

| 말 | 기준 |
|---|---|
| 비 온 날 | 하루 강수량 **1mm 이상** |
| 비 오는 주말 | 토 · 일 가운데 하루 강수량 1mm 이상인 날 |
| 반팔 주말 | 토 · 일 낮 최고기온 **25°C (77°F) 이상** |
| 연휴 | 공휴일과 토 · 일이 **휴가 없이 3일 이상** 이어지는 묶음 (징검다리 제외) |
| 기간 | **최근 10년 (2016~2025년)**, 일몰 문항은 2025년, 연휴 문항은 다가오는 2027년 |
| 공휴일 | 미국은 **연방 공휴일**만 (주마다 다른 공휴일 제외) |

## 데이터를 직접 점검하고 고친 것

- **한국 공휴일 오류 수정** — Nager.Date 의 한국 과거 공휴일에 틀린 해가 있었습니다 (2008년부터 공휴일이 아닌 제헌절이 들어 있음, 대체공휴일 · 선거일 · 임시공휴일 누락, 설 · 추석 날짜 어긋남).
  2016~2025년은 관공서 공휴일 규정과 발표된 임시공휴일로 직접 목록을 만들었습니다 (`tools/build_photobox.py` 의 `KR_HOLIDAYS`).
- **관측소와 비교** — 미국 매장 근처 관측소 4곳과 견주니 ERA5 는 **비 온 날을 1.2~1.5배 많게** 셉니다 (예: 호놀룰루 비 오는 주말 13.3일 vs 공항 관측 9.2일). 숫자는 그대로 두고 한계로 밝혔습니다.
- **흔들리는 문항 교체** — '맑은 주말이 가장 많은 달'은 구름 기준을 조금만 바꿔도 15곳 중 12곳의 답이 뒤집혀서, 기온으로 세는 '반팔 주말'로 바꿨습니다.

## 이 데이터의 한계 (결과 화면에도 나옵니다)

- 날씨는 매장 주변 **약 25km 격자의 평균값**(ERA5 재분석)이라 동네 관측소와 다를 수 있고, 비 온 날이 많게 나옵니다.
- 비 · 더위는 실내 방문 수요를 짐작하는 **대리 지표일 뿐, 실제 방문 수나 매출이 아닙니다.**
- 매장별 실제 방문 지표는 공개 데이터가 없습니다. 그래서 아래 쿠폰 구조로 **재방문을 측정할 수 있게 설계**했습니다.
- Open-Meteo 무료 API 는 **비상업용**입니다. 회사가 실제 프로모션에 쓰려면 유료 API 가 필요합니다.

## 쿠폰 · 캘린더 · 재방문 측정

- 퀴즈 끝에 고른 달에만 쓰는 **샘플 쿠폰**(10% OFF)을 줍니다.
- 쿠폰 코드는 **지역 + 달**로 만듭니다 — 예: 호놀룰루 2026년 12월 → `PD-HNL-2612`.
  매장 결제에서 코드별 사용 횟수를 세면, **어느 지역 손님이 고른 달에 실제로 다시 왔는지** 알 수 있습니다 (회사 결제 시스템 연결은 다음 단계).
- 날짜를 고르면 **Google 캘린더 일정 화면**이 채워진 채로 열리고, 애플 · 아웃룩 등은 **.ics 파일**로 추가합니다. 저장은 손님이 직접 누릅니다.

## 만든 방법

| 도구 | 한 일 |
|---|---|
| Perplexity | 키 없이 받을 수 있는 데이터 출처 찾기 |
| v0 | 화면 시안 (스티커 사진 배치 + 코발트 · 라임 색) |
| Claude Code | 데이터 받기 · 정답 계산 · 사이트 만들기 · 점검 |

```
   [내 노트북]                                         [인터넷]

   tools/fetch_all.py        Open-Meteo · Nager.Date 에서 원본 받기 (키 · 로그인 없음)
        ↓  data/raw/photobox/   ← git 에도 배포에도 올라가지 않습니다
   tools/build_photobox.py   지역 × 테마 × 3문항 정답 계산, 한국 공휴일 바로잡기
        ↓
   photobox.json             ← 이것만 올라갑니다 (화면은 이 파일만 읽음)
```

| 파일 | 하는 일 |
|---|---|
| `index.html` · `style.css` · `app.js` | PHOTO DAY 화면 (언어 · 지역 · 테마 · 문항 · 달 · 쿠폰). 계산은 하지 않고 보여 주기만 |
| `photobox.json` | 지역별 정답 · 근거 · 해설 · 한계, 달 고르기용 지역 통계 |
| `tools/fetch_all.py` | 공개 데이터 받기 (배포 제외) |
| `tools/build_photobox.py` | 원본 → 문항 계산. 기준 숫자(`RAIN_MM`, `WARM_C` 등)는 맨 위에 모여 있음 (배포 제외) |

```
python3 tools/fetch_all.py         # 원본 받기 (이미 있으면 건너뜀)
python3 tools/build_photobox.py    # 정답 다시 계산
python3 -m http.server 8000        # 미리보기 — index.html 을 더블클릭하면 안 됩니다
```

`git push` 하면 Vercel 이 자동으로 다시 올립니다.
